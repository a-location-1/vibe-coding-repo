## Overview

This repository is a collection of vibe-coded example apps. It uses a set of conventions ([CONVENTIONS.md](./CONVENTIONS.md)) to structure how projects are organized and documented. 

This repo is forked from [Paul Kaefer](https://software.stthomas.edu/about/faculty-staff/biography/paul-kaefer/index.html)'s [vibe-coding](https://github.com/paulkaefer/vibe-coding). Check the original repository for the most up-to-date recommended conventions. 

The list of app ideas ([ideas.md](./ideas.md)) is generated by Claude and edited by Paul Kaefer.
